# 实现状态

公开项目名：**robot-scratch**。当前 Python 包版本为 0.3.0，仍处于研究验证阶段。

## 已有实现

| 范围 | 当前代码 |
| --- | --- |
| fake 闭环 | 固定控制图、单组多端点、所有权/epoch、动作检查、MCAP 与只读回放 |
| 设备配置 | 被动发现、显式身份绑定、JSON 模板、静态预检 |
| 遥操 | WebXR、会话状态机、侧握位姿控制、独立扳机夹爪、WSS/可选 WebRTC |
| 运动 | FK、可选 Pinocchio/SciPy IK、独立 solver worker、执行网关 |
| 相机 | 三路角色模板、capture/preview/record 分离、最新帧预览、可配置 QoS |
| 采集 | 原始 MCAP 或 RGB MP4、有界异步磁盘队列、episode 保存/丢弃、索引、对齐与 QC |
| 数据消费 | 原生/转换末端 provenance、因果训练视图、已发布目标轨迹构建 |
| 回放与假模型 | native 工作流绑定、起始对齐、独立进程 HTTP mock policy、共同执行入口 |

这些是代码范围，不是对所有机器人、操作系统或网络条件的硬件认证。
M1 固定 fake 切片已完成；现有真机路径仍以部署环境独立验证为准。
